# Challenging Real-World Problems

Taking on real problems with AI: unsolved math problems, and products that
solve problems in everyday life.

| Project | What it is | Status |
|---------|------------|--------|
| [a280537](a280537/) | New lower bound **a(28) ≥ 58** for [OEIS A280537](https://oeis.org/A280537) (no four points in a plane) | Result found and verified |
| [say-and-build](say-and-build/) | Describe the furniture you want, get a checked plan you can actually build | First version |
| [what-if-world](what-if-world/) | A world simulator: write any event and watch how countries, markets and people react week by week, sized by real historical cases | First version |
| [ai-power-plant](ai-power-plant/) | AI neighborhood power plant: how much homes save by shifting appliances to cheap hours and sharing neighbors' solar, using real German data | Finished (stopped after step 2, see devlog) |
| [ai-stops-early](ai-stops-early/) | Why AI fails at hard problems: not a belief that they are impossible, but settling for a plausible answer. Six experiments with OpenAI models | Six runs done, run 7 next |

Each folder has its own README.
